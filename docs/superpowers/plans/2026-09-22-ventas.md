# Punto de venta (Ventas) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Agregar un punto de venta: rol `VENDEDOR`, una pantalla de venta que descuenta stock automáticamente, un historial con anulación, y un comprobante interno imprimible (no fiscal).

**Architecture:** Sigue exactamente el patrón ya establecido por el módulo de inventario: Server Components para lecturas (`server/queries/sales.ts`), Server Actions para escrituras (`server/actions/sales.ts`, `'use server'`, Zod, `prisma.$transaction`, `revalidatePath`), y el mismo ledger `InventoryTransaction` para el descuento/reposición de stock (nuevos tipos `VENTA`/`ANULACION`) en vez de una tabla de movimientos separada.

**Tech Stack:** Igual que el resto del proyecto — Next.js 16 App Router, Prisma + PostgreSQL, Zod, Tailwind v4, Radix UI, Vitest + RTL.

**Spec:** `docs/superpowers/specs/2026-09-22-ventas-design.md` — leer antes de ejecutar.

## Global Constraints

- **Next.js 16 — APIs cambiadas.** `params` es una `Promise` (`await params`); Server Actions son invocables directo desde componentes cliente sin necesidad de un route handler.
- **Toda Server Action mutante empieza con `await requireRole([...])` o `requireUser()`** — sin excepción, incluso si la UI ya oculta el botón para roles sin permiso.
- **Toda mutación de stock ocurre dentro de `prisma.$transaction`** — nunca escribir `InventoryStock` sin insertar el `InventoryTransaction` correspondiente en la misma transacción.
- **Ventas nunca se borran físicamente.** Anular es `cancelledAt`/`cancelledById`, nunca `DELETE`. (Esto es una excepción deliberada al borrado físico que sí usa el catálogo — una venta es un registro contable.)
- **Montos:** `Decimal(12, 2)`. **Cantidades:** enteros ≥ 1 por línea de venta. Moneda: ARS vía `money()`/`integer()` de `@/lib/format` — nunca reimplementar el formateo.
- **`prisma migrate dev` no corre en este entorno** (no hay TTY interactivo) — cada migración de este plan se escribe a mano siguiendo el formato SQL plano de Prisma, y se aplica con `prisma migrate deploy` (`pnpm run test:db:migrate` / `pnpm run db:deploy`).
- **Responsive (spec §3.7 del proyecto):** breakpoint `md` (768px) tabla↔tarjetas, targets táctiles `min-h-11`, `inputMode="numeric"` en cantidades, sin scroll horizontal de página, `Dialog` bottom-sheet en `<sm`.
- **Idioma:** UI, rutas y mensajes de error en español; identificadores de código en inglés/PascalCase donde ya es la convención (nombres de tipos, enums de Prisma).
- **Commits:** uno por tarea como mínimo, Conventional Commits, terminando con `Co-Authored-By: Claude Sonnet 5 <noreply@anthropic.com>`.
- **Impresión:** navegador estándar (`window.print()`), sin integración con impresora térmica/ESC-POS ni con AFIP/ARCA — el comprobante debe incluir el texto "Documento no válido como factura."

## Review Focus

- **Vender un producto sin precio cargado** (ni `variant.price` ni `product.defaultPrice`): el sistema no debe vender "gratis" en silencio — debe rechazar la venta con un error claro. Cubierto en Task 5.
- **La misma variante aparece dos veces en un solo `createSale`** (llamada directa a la action con un payload armado a mano, sin pasar por el merge del carrito): debe fusionarse antes de validar stock, no evaluar cada línea contra el stock original por separado. Cubierto en Task 5.
- **Vender más cantidad de la que hay disponible** en cualquier línea: la venta completa se rechaza, no se persiste nada (ni siquiera las líneas que sí alcanzaban). Cubierto en Task 5.
- **Anular una venta con un `id` que no existe**, y **anular una venta ya anulada**: ambos casos deben devolver un error claro, no un 500 ni una segunda anulación silenciosa. Cubierto en Task 6.
- **Buscar con menos de 2 caracteres** en el buscador de venta: debe devolver una lista vacía, igual que el resto de las búsquedas del proyecto — no debe listar todo el catálogo ni tirar error. Cubierto en Task 4.

```ts
import 'server-only'
import { prisma } from '@/server/db'
import { effectivePrice, toNumber } from '@/lib/pricing'
import type { PaymentMethodName } from '@/lib/constants'

export type SellableVariant = {
  variantId: string; productName: string; variantName: string; categoryName: string
  quantity: number; unitPrice: number | null
}

export async function searchSellableVariants(q: string, limit = 20): Promise<SellableVariant[]> {
  const term = q.trim()
  if (term.length < 2) return []
  const like = { contains: term, mode: 'insensitive' as const }
  const rows = await prisma.productVariant.findMany({
    where: { OR: [{ name: like }, { product: { name: like } }] },
    take: limit,
    orderBy: [{ product: { name: 'asc' } }, { name: 'asc' }],
    include: {
      stock: true,
      product: { select: { name: true, defaultPrice: true, category: { select: { name: true } } } },
    },
  })
  return rows.map((v) => ({
    variantId: v.id, productName: v.product.name, variantName: v.name,
    categoryName: v.product.category.name, quantity: v.stock?.quantity ?? 0,
    unitPrice: effectivePrice({ price: toNumber(v.price) }, { defaultPrice: toNumber(v.product.defaultPrice) }),
  }))
}

export type SaleRow = {
  id: string; number: number; createdAt: Date; userName: string
  paymentMethod: PaymentMethodName; total: number; cancelledAt: Date | null
}

export async function listSales(): Promise<SaleRow[]> {
  const rows = await prisma.sale.findMany({
    orderBy: { createdAt: 'desc' },
    include: { user: { select: { name: true } } },
  })
  return rows.map((s) => ({
```

```ts
'use server'
import { revalidatePath } from 'next/cache'
import { prisma } from '@/server/db'
import { requireRole } from '@/server/auth/guards'
import { effectivePrice, toNumber } from '@/lib/pricing'
import { createSaleSchema } from '@/server/validation/sales'
import { searchSellableVariants, type SellableVariant } from '@/server/queries/sales'

export type CreateSaleResult =
  | { ok: true; saleId: string; number: number }
  | { ok: false; error: string }

export async function createSale(input: unknown): Promise<CreateSaleResult> {
  const session = await requireRole(['ADMIN', 'VENDEDOR'])
  const parsed = createSaleSchema.safeParse(input)
  if (!parsed.success) return { ok: false, error: parsed.error.issues[0].message }

  // Fusiona líneas repetidas de la misma variante antes de validar stock —
  // evita que dos líneas de la misma variante se validen cada una contra el
  // mismo stock original y terminen sobrevendiendo.
  const merged = new Map<string, number>()
  for (const item of parsed.data.items) {
    merged.set(item.variantId, (merged.get(item.variantId) ?? 0) + item.quantity)
  }
  const items = [...merged.entries()].map(([variantId, quantity]) => ({ variantId, quantity }))

  const result = await prisma.$transaction(async (tx) => {
    const lines: { variantId: string; quantity: number; unitPrice: number; subtotal: number }[] = []
    let total = 0

    for (const item of items) {
      const variant = await tx.productVariant.findUnique({
        where: { id: item.variantId },
        include: { stock: true, product: { select: { name: true, defaultPrice: true } } },
      })
      if (!variant) return { error: 'Producto no encontrado' }

      const available = variant.stock?.quantity ?? 0
      if (item.quantity > available) {
        return { error: `No hay stock suficiente de ${variant.product.name} · ${variant.name} (quedan ${available})` }
      }

      const unitPrice = effectivePrice({ price: toNumber(variant.price) }, { defaultPrice: toNumber(variant.product.defaultPrice) })
      if (unitPrice === null) {
        return { error: `${variant.product.name} · ${variant.name} no tiene precio cargado` }
      }

      const subtotal = unitPrice * item.quantity
      total += subtotal
      lines.push({ variantId: item.variantId, quantity: item.quantity, unitPrice, subtotal })
    }

    const sale = await tx.sale.create({
      data: {
        userId: session.sub,
        paymentMethod: parsed.data.paymentMethod,
        total,
        items: { create: lines },
      },
    })

    for (const line of lines) {
      const current = await tx.inventoryStock.findUnique({ where: { variantId: line.variantId } })
      const before = current?.quantity ?? 0
      const after = before - line.quantity
      await tx.inventoryStock.update({ where: { variantId: line.variantId }, data: { quantity: after } })
      await tx.inventoryTransaction.create({
        data: {
          variantId: line.variantId, type: 'VENTA', quantityDelta: -line.quantity, quantityAfter: after,
          userId: session.sub, batchId: sale.id,
        },
      })
    }

    return { sale }
  })

  if ('error' in result) return { ok: false, error: result.error }
  revalidatePath('/deposito')
  revalidatePath('/ventas')
  return { ok: true, saleId: result.sale.id, number: result.sale.number }
}
```

```ts
export type ActionResult = { ok: true } | { ok: false; error: string }

export async function cancelSale(id: string): Promise<ActionResult> {
  const session = await requireRole(['ADMIN', 'VENDEDOR'])
  const sale = await prisma.sale.findUnique({ where: { id }, include: { items: true } })
  if (!sale) return { ok: false, error: 'Venta no encontrada' }
  if (sale.cancelledAt) return { ok: false, error: 'Esta venta ya fue anulada' }

  await prisma.$transaction(async (tx) => {
    for (const item of sale.items) {
      const current = await tx.inventoryStock.findUnique({ where: { variantId: item.variantId } })
      const before = current?.quantity ?? 0
      const after = before + item.quantity
      await tx.inventoryStock.upsert({
        where: { variantId: item.variantId },
        update: { quantity: after },
        create: { variantId: item.variantId, quantity: after },
      })
      await tx.inventoryTransaction.create({
        data: {
          variantId: item.variantId, type: 'ANULACION', quantityDelta: item.quantity, quantityAfter: after,
          userId: session.sub, batchId: sale.id,
        },
      })
    }
    await tx.sale.update({ where: { id }, data: { cancelledAt: new Date(), cancelledById: session.sub } })
  })

  revalidatePath('/deposito')
  revalidatePath('/ventas')
  revalidatePath(`/ventas/${id}`)
  return { ok: true }
}
```

```tsx
'use client'
import { useState } from 'react'
import { useRouter } from 'next/navigation'
import { cancelSale } from '@/server/actions/sales'
import { useToast } from '@/components/ui/toast'

export function CancelSaleButton({ saleId }: { saleId: string }) {
  const router = useRouter()
  const { toast } = useToast()
  const [pending, setPending] = useState(false)

  async function handleCancel() {
    if (!window.confirm('¿Seguro que querés anular esta venta? Repone el stock vendido.')) return
    setPending(true)
    const res = await cancelSale(saleId)
    setPending(false)
    if (!res.ok) {
      toast(res.error, 'danger')
      return
    }
    toast('Venta anulada', 'success')
    router.refresh()
  }

  return (
    <button type="button" onClick={handleCancel} disabled={pending}
      className="min-h-11 px-3 rounded border border-danger text-danger text-sm disabled:opacity-60">
      {pending ? 'Anulando…' : 'Anular venta'}
    </button>
  )
}
```
